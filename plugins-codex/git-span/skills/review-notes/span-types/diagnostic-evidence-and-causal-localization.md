# Diagnostic evidence and causal localization

Scope: add and update spans for diagnostic evidence and causal localization.

## When to use this type

An opaque symptom admits multiple causes and evidence must cross a boundary to choose a repair. Bound and sanitize diagnostics; a repaired shared prerequisite permits downstream execution without proving its correctness.

## Information and anchors

Name candidate causes, evidence origin, fields/channel retained, correlation identity and the conclusions each observation supports.

Candidate anchor roles: evidence-producing stage; lossy wrapper; diagnostic schema/consumer; bounded worked decomposition. Select existing content carrying the rule or likely to be encountered at the risky decision. These are roles, not a required anchor count.

## Add or update a span

1. Locate the rule and participating locations using the anchor roles above. Preserve its authority, scope and evidence limits in the why.
2. Inspect existing spans at those locations. Extend useful coverage; otherwise add a span following step 3 in [the skill](../SKILL.md). A useful single-anchor reminder is eligible.
3. Update anchors and the why when the relationship changes; preserve unresolved authority or interpretation explicitly.

## Illustrative why

> Compiler failures retain stage, status and captured stderr through the runner envelope; solution stdout remains separate from machine results.
