git-mora-branch

Create a uniquely named agent branch and print its name

Usage: git mora branch [OPTIONS] --agent-id <id> [START_POINT]

Arguments:
  [START_POINT]
          Starting commit or branch; defaults to HEAD

Options:
      --agent-id <id>
          Agent/session identifier

      --target <branch>
          Intended publication target; defaults to the current branch's literal name

  -h, --help
          Print help
