git-mora-listen

Watch for matching tags and branches being created

Usage: git mora listen [OPTIONS] [-- <command>...]

Arguments:
  [command]...
          Command invoked once per match with the JSON line on stdin

Options:
      --tag <pattern>
          Ordinary tag name pattern, e.g. 'pending/main/*'

      --branch <pattern>
          Ordinary branch name pattern, e.g. 'agent/alice/*'

      --agent-id <id>
          Parsed agent, or the current branch association for a tag

      --target <name>
          Target encoded in a workflow name

      --attempt-id <id>
          Attempt encoded in a workflow name

      --topic <id>
          Direct topic membership of the pointed-to commit

      --existing
          First emit current matches (labeled 'existing')

      --once
          Exit after the first match is emitted or its callback succeeds

      --poll-interval <d>
          Observation interval
          
          [default: 1s]

  -h, --help
          Print help
