git-mora-wait

Wait for matching tags or branches to exist or disappear

Usage: git mora wait [OPTIONS]

Options:
      --tag <pattern>
          Ordinary tag name pattern, e.g. 'pending/main/*'

      --branch <pattern>
          Ordinary branch name pattern, e.g. 'agent/alice/*'

      --agent-id <id>
          Parsed agent, or the current branch association for a tag

      --target <name>
          Target encoded in a workflow name

      --attempt-id <id>
          Attempt encoded in a workflow name

      --topic <id>
          Direct topic membership of the pointed-to commit

      --absent
          Wait until no names satisfy the filters

      --timeout <d>
          Stop after this duration (exit 3)

  -h, --help
          Print help
