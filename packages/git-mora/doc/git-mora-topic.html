git-mora-topic

Create, inspect, and update informational topic associations

Usage: git mora topic <COMMAND>

Commands:
  create   Create an empty topic (an existing valid topic is unchanged)
  list     List topic ids
  show     Show the commits associated with a topic
  of       List topics directly containing a commit
  add      Union commits into a topic, creating it if needed
  context  Manage this worktree's future-commit topic context
  exec     Run a command with command-scoped topic context
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help
