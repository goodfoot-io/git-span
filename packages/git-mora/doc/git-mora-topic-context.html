git-mora-topic-context

Manage this worktree's future-commit topic context

Usage: git mora topic context <COMMAND>

Commands:
  show   Show effective topics, their source, and any ignored binding
  set    Replace this worktree's context and bind it to the current branch
  clear  Bind an explicitly empty context to the current branch
  help   Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help
