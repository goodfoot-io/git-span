git-mora-tag

Tag the current attempt as pending, merge, or discard

Usage: git mora tag <COMMAND>

Commands:
  pending  Create the pending tag at HEAD (requires a clean worktree)
  merge    Turn the pending snapshot at HEAD into a merge tag
  discard  Turn the pending or merge snapshot at HEAD into a discard tag
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help
