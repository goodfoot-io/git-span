git-mora-hook

Run a topic-tracking adapter from an existing Git hook

Usage: git mora hook <COMMAND>

Commands:
  post-commit   Add the new HEAD to the effective topic context
  post-rewrite  Carry topic membership onto rewritten commits (reads old/new pairs on stdin)
  post-merge    Annotate a newly created merge commit
  help          Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help
